## 2. 收录原则（红线）

1. **只收公有领域古籍原文**（作者卒于 1911 年之前的传世古籍）；现代整理本的**标点/排版/译注有版权，不得复制**。
2. 每条断语必须四要素齐全：**原文 + 出处（书名/卷/篇）+ 校对底本（URL）+ 断语要点 + 适用因子**。
3. **状态机**：`seed`（检索落盘）→ `reviewed`（人工对照在线底本逐字校核通过）。**未 reviewed 不得注入 AI prompt**。
4. 白话释义只可**自撰**，标注为观微整理，不抄任何现代译本表述。
5. 无成书古籍的术数（如小六壬）：收录民间口诀须注明「民间流传、非古籍成书」并附版本说明。
