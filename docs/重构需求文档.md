## 1. 重构愿景

### 1.1 产品定位（升级）
从"塔罗为中心的占卜工具"升级为 **"以宋式美学为衣、以东玄七术为主、九术兼备的玄学问道平台"**。

- **品牌名**：观微（副题：以术问道 · 观微知著）
- **九术体系**：
  - 东玄七术（主力）：四柱八字、紫微斗数、奇门遁甲、梅花易数、六爻、大六壬、小六壬
  - 西玄二术（辅助）：星盘、塔罗
- **三大新增板块**：AI 深度解读（增强准确性）、古籍典藏（溯源）、观微学馆（学习）

### 1.2 重构原则
1. **UI/交互以参考项目为准**：宋式美学设计系统、册页导航、工作台模式、hash 路由与页面进出关系，全部沿用参考项目的既定范式
2. **东玄为主**：东玄七术在册页排序、内容深度、AI 解读优先级上均高于西玄二术
3. **算法准确性优先**：以参考项目 verify-final.js 的 30+ 校验用例为基线，全部术数算法必须通过校验；重建后补充更多用例
4. **AI 解读增强**：每一术结果均可触发 AI 深度解读，结合排盘结果与用户问题生成个性化解读
5. **资产复用**：原始项目中的完整塔罗数据（78 张、深意体系）、牌阵库/编辑器、历史记录、LLM 多 Provider 引擎、用户记忆系统，全部融合进新架构
6. **合规先行**：全局沿用"观微三戒"免责声明，AI 解读强制携带免责声明

### 2.2 路由规则（页面进出约束）

```
#home        首页（含 九术册页 / 观微三法 两个锚点区）
#home-arts   首页·九术册页锚点
#home-fa     首页·观微三法锚点

#art:xiaoliuren 小六壬模块  #art:astrology 星盘模块

```

**进出规则（必须严格遵守）**：
1. 顶部菜单点击任意链接：切换到对应视图，`active` 高亮仅落在与当前视图匹配的菜单项上；九术模块视图激活时，菜单高亮落在"九术"
2. 进入九术模块：从九术册页卡片点击进入，视图切换到对应 `#art:xxx`，**滚动至顶部**
3. 模块内返回：每个模块页提供"返册页"（返回 #home-arts）与"首页"（#home）两个出口；浏览器后退键（hash 历史）必须可用
4. 视图切换动画：`viewIn` 淡入上移 0.9s，切换时旧视图立即隐藏
5. 模块视图懒加载：首次进入才注入 DOM，再次进入不重建（保留输入与结果状态）
6. 历史记录页进入某条记录详情后，返回键回到历史列表，不丢失列表滚动位置

## 4. 功能业务需求（九术）

### 4.0 通用规则
1. **每术 = 输入面板 + 起占按钮 + 结果区**，结果区初始为占位态
2. **算法准确性**：全部算法必须通过第 7 章校验用例；输入非法值给出提示而非崩溃
3. **每术结果底部提供**："AI 深度解读"入口（见第 5 章）、"存入历史"（见第 8 章）
4. **术数溯源**：每术模块页展示出处（如"源于唐·李虚中《李虚中命书》…"），并可跳转古籍页对应典籍
5. **免责声明**：每术结果区底部常驻

### 4.1 四柱八字（东玄 · 壹）—— P0

- **输入**：公历出生日期、时辰（12 时辰下拉）、性别、出生地点（北京/上海/广州/深圳/成都/其他-东八区，结构为省市县区对应经纬度）
- **输出**：
  1. 四柱命盘卡：年/月/日/时柱干支、五行（天干+地支）、十神（以日主定）、宫位含义（祖上·幼年等）、纳音
  2. 五行流转卡：五行计数（●×N）、日主强弱判定（身强/身弱/中和，按生扶 vs 克泄耗计数）、喜忌简述、年命纳音
  3. 十神六亲卡：各柱天干十神解释、十神总义
- **算法要点**：年柱以立春为界；月柱以节气定支 + 五虎遁；日柱儒略日推算（daysSince +16 mod 60）；时柱五鼠遁
- **已知限制（标注给用户）**：节气取近似日期，精确排盘需万年历校正

### 4.2 紫微斗数（东玄 · 贰）—— P0

- **输入**：生年（干支下拉 1950-2010）、农历月/日、时辰、出生地点（北京/上海/广州/深圳/成都/其他-东八区，结构为省市县区对应经纬度）、性别
- **输出**：
  1. 星盘信息卡：五行局（纳音定局）、纳音、命宫地支、紫微落宫
  2. 4×4 紫微盘网格：十二宫（地支位）布十四主星，命宫朱砂"命"标记，中央"观微·紫微简盘"
  3. 主星释义卡：14 主星逐一释义（帝星/智星/… + 详解）
- **算法要点**：命宫（寅宫起正月顺数至生月，子时起逆数至生时）；五行局；紫微定位（金四局顺/他局逆）；紫微系 6 星 + 天府系 8 星偏移定位
- **标注**：演示级简盘（辅曜从略）

### 4.3 奇门遁甲（东玄 · 叁）—— P0

- **输入**：用事时刻（datetime-local）、所问何事（择时出行/谋事求财/讼事纠纷/考试功名/婚恋姻缘/疾病求医/其他）
- **输出**：
  1. 局式信息卡：节气、阴阳遁、局数、日时干支、旬首（甲子遁戊等）、值符星、值使门
  2. 九宫盘（3×3）：每宫三奇六仪 + 八门 + 九星，中宫"中五寄坤"
  3. 用事提示：阳遁主动宜进 / 阴遁主静宜守；值符宫为发端，值使门主出入
- **算法要点**：节气定阴阳遁 → 候（三元）定局数 → 三奇六仪顺/逆布九宫 → 值符值使 → 八门九星布列
- **标注**：演示级起局（三候取元为粗略）

### 4.4 梅花易数（东玄 · 肆）—— P0

- **输入**：起卦方式（时间起卦 / 报数起卦 1-999×3）、所问之事（可留白，≤24 字）
- **输出**：
  1. 起卦信息卡：上卦/下卦/动爻（含卦符）
  2. 卦象卡：本卦（爻画 + 卦辞 + 象辞）、互卦、变卦
  3. 体用生克卡：体卦（事主）/用卦（所问），生克断语（用生体吉/体克用吉/用克体凶/体生用泄气/比和平），并翻译成通俗建议
  4. 卦辞指引卡：本卦卦辞原文 + 释读
- **算法要点**：时间起卦（年支序+月+日 → 上卦；+时 → 下卦与动爻）；报数起卦；本/互/变卦爻位演算；体用按动爻位置判定

### 4.5 六爻（东玄 · 伍）—— P0

- **输入**：所问之事（可留白）；三枚"宋通宝"铜钱虚拟摇卦（真随机 0-3 背）
- **输出**：
  1. 摇卦卡：六枚铜钱（几背几字）+ 六爻爻线（自下而上）+ 老阴/少阳/少阴/老阳标记，动爻朱砂○×
  2. 卦象卡：本卦/变卦（卦名 + 象辞），动爻数量与位置
  3. 卦辞卡：本卦卦辞原文 + 动变指引（"第N爻发动，变卦为事之归趋"/"六爻安静，宜守其常"）
- **算法要点**：三枚铜钱 = 0-3 背随机，4 种组合对应老阴/少阳/少阴/老阳；老阴老阳为动爻（变卦取反）
- **增强方向（二期）**：补六亲六神、世应纳甲（需完整 64 卦卦辞库，参考项目仅含卦辞与象辞）

### 4.6 大六壬（东玄 · 陆）—— P0

- **输入**：占时（datetime-local）、所占之事（问出行/财利/讼事/姻缘/疾病/失物/家宅/其他）
- **输出**：
  1. 课式卡：当前节气、月将（登明/河魁…+ 地支）、日干支、占时干支
  2. 天地盘卡：十二宫（地支 + 生肖）→ 天盘支（含五行、月将名）
  3. 四课三传卡：干上/干阴/支上/支阴四课；初传→中传→末传（简式取传），并释义（事发之端/事进之中/事成之归；干外支内）
- **算法要点**：月将随太阳过宫（中气定将，16 个日期校验用例）；月将加时顺布天盘；四课由日干支遁干与支起；三传简式
- **标注**：简式取传，精确起课需正时与月将过宫校正（二期可升级九宗门）

### 4.7 小六壬（东玄 · 柒）—— P0

- **输入**：取数方式（农历月日时 / 随取三数 1-12）
- **输出**：
  1. 掌诀卡：吉凶（吉/凶，朱砂/豆青）、五行、主数、方位、掌诀原文（如"大安事事昌…"）
  2. 推演轨迹卡：逐步展示"大安起月 → 月N落X → 日N落Y → 时N终落Z"的推算过程
- **算法要点**：大安起月 → 月上起日 → 日上起时，每步 mod 6 顺数

### 4.8 星盘（西玄 · 捌）—— P1

- **输入**：出生日期、出生时刻、出生地点（北京/上海/广州/深圳/成都/其他-东八区，结构为省市县区对应经纬度）、性别
- **输出**：
  1. 命盘卡：上升（近似）、太阳、月亮落座；行星逐位（7 星：黄经→星座+度数，星座释义）
  2. 相位卡：合/六合/刑/拱/冲（容差 8°），相位释义
  3. 十二宫卡：整宫制（命宫=上升座），十二宫名+星座
- **算法要点**：行星黄经近似（平均运动），上升近似（太阳+（时-6）×15°）；整宫制
- **标注**：简略天文近似，仅供怡情（二期接入真实天文库 astronomy.browser.min.js 或 lunar.js 精度升级）

### 4.9 塔罗（西玄 · 玖）—— P1（融合原始项目增强）

- **输入**：所问之事（可留白）、抽取张数（单张·今日之示 / 三张·过去当下未来）
- **输出**：
  1. 洗牌抽牌卡：扇形牌面，点击逐张翻开（正/逆位随机）
  2. 牌阵之示卡：每张牌位（过去之象/当下之境/未来之趋）、正逆位、释义
- **数据增强**：以原始项目 78 张完整数据（深意/生活领域/故事/意象/神秘学关联）**替换参考项目的简版数据**，保留参考项目的翻牌交互
- **牌阵扩展（二期）**：融合原始项目牌阵库（17 预设 + 自定义编辑器），塔罗模块可选牌阵

### 4.10 万年历黄历与每日星相/运势/星座（新增，P0）

- **今日黄历面板**（首页）：农历日期、干支、生肖、当日节气、月相、黄历宜忌（宜/忌、冲煞、吉神凶煞）——数据来自开源万年历库（lunar-typescript）
- **每日星相面板**（首页）：当日行星位置（共享星盘算法）、月相、节气提示
- **每日运势**：
  - 未登录：按当日太阳星座的通用版运势
  - **登录后：根据用户出生信息（出生年月日时 + 出生地省市县区经纬度）计算个人出生星盘，再与当日天象对照生成个性化每日运势**（规则模板 + 可选 AI 深化）
- **每日星座**：登录用户展示其太阳/月亮/上升星座及当日行运解读；出生时辰与地点通过真太阳时校正后参与计算
- 用户出生信息在登录后自动预填各术输入面板（八字/紫微/星盘）

## 5. AI 深度解读（新增，P0）

### 5.1 定位
九术排盘/起卦结果均为"确定性演算"（事实层），AI 解读在其上生成"洞见层"：结合用户问题、排盘事实、用户历史记忆，产出个性化、有温度的解读。

### 5.2 功能需求

| 需求 | 说明 |
|---|---|
| 入口 | 每术结果区底部"AI 深度解读"按钮；未填问题时用"心念未书"占位 |
| 输出 | 分段长文（结构：① 排盘事实摘要 ② 与所问之事的对应 ③ 建议与警示 ④ 结语）；流式输出（逐段/逐字，参考原始项目 SSE 经验） |
| 上下文 | 系统提示（术数专家人设 + 该术规则）+ 排盘结果 JSON + 用户问题 + 语义分析 + 用户近期历史（≤5 条，脱敏） |
| 多 Provider | Gemini / Groq / DeepSeek / Qwen / 自定义 OpenAI 兼容端点（沿用原始项目 llm-engine-v6.js 的适配层）；失败自动降级为规则模板解读（沿用原始项目 tarotEngine 的规则解读作为保底） |
| 合规 | 提示词强制约束：不作医疗/法律/投资/重大决策建议；输出尾部自动附加免责声明；敏感话题（疾病/死亡/诉讼）使用审慎话术 |
| 个性化 | 结合用户记忆（最近主题/常问领域）微调解读侧重点 |
| 记录 | AI 解读全文随占卜记录存档 |

### 5.3 语义分析复用
沿用原始项目 semanticAnalyzer（场景/情绪/时态/对象/问题类型/实体/潜台词），作为 AI 解读的输入与规则解读的素材。

## 6. 古籍典藏与观微学馆（新增）

### 6.1 古籍典藏（#classics）—— P1

- **典籍清单（首期 ≥12 部）**，按九术归类：
  - 命理：《渊海子平》《三命通会》《滴天髓阐微》《子平真诠》《穷通宝鉴》

  - 筮法：《周易》《梅花易数》《增删卜易》《卜筮正宗》
  - 三式：《六壬大全》《奇门遁甲统宗》《烟波钓叟歌》
- **每部典籍**：书名、作者/编者、年代、成书背景、核心内容提要、篇章目录、与九术的关联、原文选段（含译文与注释）
- **能力**：分类浏览（按术）、搜索（书名/作者/内容）、详情页（#classics:id）、原文-译文对照阅读、"关联术数"跳转对应模块
- **数据来源**：首期以整理公开领域原文选段为主，标注版本与来源；不做全文收录（版权合规）

### 6.2 观微学馆（#academy）—— P1

- **课程体系**：

  - 各术入门：八字基础（十神/强弱）、紫微入门（十四主星/十二宫）、梅花起卦、六爻摇卦、小六壬掌诀、奇门九宫、大六壬月将
  - 进阶专题（二期）：大运流年、格局判断、卦象断事、古籍研读
  - 西玄入门：星座与行星、塔罗大阿卡纳之旅
  - 占问之道：静/诚/悟三法（源自参考项目法度）
- **课程形式**：图文讲义（分节）、要点卡片、互动练习（如：给出日期算日柱并自检）、关联古籍延伸阅读
- **课程数据模型**：id、术属、标题、难度、章节[]（标题+正文+图表）、练习[]（题干+答案+解析）、关联典籍 id[]

## 7. 算法准确性要求（校验基线）

### 7.1 原则
1. 参考项目 verify-final.js 全部用例必须通过（移植为单元测试）
2. 每术至少覆盖：边界日期（节气交界/闰年/跨年）、已知日期对照（如 1990-06-15 午时 = 庚午/壬午/壬申/丙午）、随机稳定性（六爻 50 次、塔罗牌池完整性）
3. 新增用例：八字节气边界（2024-02-03 vs 02-05）、大六壬月将 16 日期、紫微五行局 6 组对照

### 7.2 校验用例清单（移植基线）

| 术 | 关键用例 |
|---|---|
| 八字 | 1990-06-15 午时四柱；2024 立春前后年柱/月柱切换；纳音对照（1990 路旁土/1993 剑锋金） |
| 紫微 | 6 组干支→纳音→五行局对照；命宫（正月子时@寅/午时@申）；紫微金四局定位 |
| 奇门 | 阴阳遁类型；局数 1-9；九宫 1-9 覆盖；值符值使非空 |
| 梅花 | 报数 1/2/3 → 天泽履、动爻 3；时间起卦输出完整；体用判语 |
| 六爻 | 50 次均有本卦；动爻存在时变卦必在；6 爻结构 |
| 大六壬 | 16 个日期→月将对照（1/1 丑、1/20 子、2/19 亥…12/22 丑）；四课三传非空 |
| 小六壬 | 正月初一子时=大安；六月初一子时=空亡；报数 3/3/3=大安；3/1/5=大安 |
| 星盘 | 1990-06-15 太阳黄经≈82.9°（双子末）；7 行星齐全 |
| 塔罗 | 牌池 78 张；抽 N 张不重复；正逆位字段 |
| 数据 | ARTS 九术唯一；GUA64 64 条键/名唯一；MAJOR 22；XLR 6 |

## 10. 语言风格规范（三层文案）

| 层 | 适用场景 | 风格 | 示例 |
|---|---|---|---|
| 古风提示层 | 界面提示：按钮/placeholder/hint/引导语/空态/免责声明 | 文言古风短句，克制雅致 | 起卦/排盘/掐指一算；默念所问，心念自随；静心片刻，一念一事；静候卦象，观微知著 |
| 现代解读层 | 排盘/起卦结果占断、AI 解读正文 | 现代白话、直白有温度、不绝对化 | 本卦提醒您行事谨慎，如履薄冰，宜先看清脚下 |
| 古籍话术层 | 古籍原文引用（卦辞/掌诀/典籍选段） | 保持古籍原文话术，附现代注译与出处 | 「元亨利贞。天行健，君子以自强不息。」（《周易·乾卦》） |

**规则**：UI 文案集中管理并标注「古」标记；解读生成器（规则模板/AI 提示词）一律现代语言，引经据典以引用块呈现并标注出处；AI 提示词约定三段式（现代解读 + 古籍引证 + 免责尾注）。
